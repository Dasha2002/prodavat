# Фирменная графика

Иконки `img/brand/icon-*.svg`, белый логотип `logo-white.svg` и фигура
`brand-mark.svg` экспортированы из векторных контуров ранее предоставленного
файла «брендбук.pdf». Это исходная графика бренда, а не перерисовка по скриншоту.

- Страница 9: девять тематических иконок и белый логотип в подвале слайда.
- Страница 16 PDF: крупная фоновая фигура (на самом слайде указан номер 12).
- Цвет фигуры для сайта: фирменный бордовый `#8d1223`.
