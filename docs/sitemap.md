# Карта и дальнейшее развитие

Готовы главная, контакты и шесть внутренних страниц в общем стиле. Новые страницы подключены к меню и футеру. Дополнительные будущие разделы отмечены ниже.

| Страница | Маршрут | Секции / статус |
|---|---|---|
| Главная | / | Предложение → задачи → изменения → услуги → эксперты → этапы → кейсы → отзывы → FAQ → заявка. Готова, кейсы и отзывы ждут реальных данных. |
| Контакты | /kontakty/ | Связь → онлайн-формат → реквизиты → форма. Готова с демонстрационными данными. |
| Форматы работы | /formaty-raboty/ | Готова: два формата → сравнение → выбор → обращение. |
| Комплексный аудит | /formaty-raboty/audit-prodazh/ | Готова: кому подходит → схема этапов → материалы на выходе → условия → следующий формат → обращение. |
| Построение отдела продаж | /formaty-raboty/otdel-prodazh/ | Готова: задачи → этапы внедрения → результат → организация проекта → обращение. |
| О нас | /o-nas/ | Готова: команда → взгляд на продажи и людей → принципы → совместная работа → встреча. |
| Практика | /praktika/ | Готова: три раскрывающихся примера разбора задач → оценка изменений → обращение. Примеры не представлены как реальные кейсы. |
| Отзывы | /otzyvy/ | Готова: демонстрационные карточки с раскрытием → заглушки площадок → модалка отзыва → обращение. |
| База знаний | /baza-znaniy/ | Каталог с фильтрами по темам. Все карточки ведут на общую страницу-шаблон статьи. |
| Кейсы | /keisy/ | Проекты с задачами и результатами → рекомендации → заявка |
| Кейс | /keisy/{slug}/ | Контекст → ситуация → диагностика → действия → результаты → отзыв → услуга |
| Материалы | /materialy/ | Избранное → темы → услуги |
| Статья | /baza-znaniy/statya/ | Общий шаблон: заголовок → фотография → оглавление → текстовые разделы → форматы работы → форма. |
| Стратегическая встреча | /vstrecha/ | Платность и 30 минут → аудитория → содержание → участники → запись → форма → FAQ |

Копирайтинг — проект текста по карте сайта и брендбуку, требует согласования владельцем. Цены, сроки, биографии и численные результаты не выдумывались. Кнопки двух форматов на главной ведут на подробные страницы; кнопки обсуждения задачи открывают форму с параметром service. Отправка заявок и публикация отзывов пока не подключены.
