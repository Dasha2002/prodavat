# Портреты для серого hero

Инструмент: встроенный imagegen, режим background-extraction, прозрачный фон.

Результат: `img/team/hero-portraits-neutral.png`. Исходники: `DSC_6388.jpg` и `DSC_7141.jpg`.

Промпт: убрать только студийный фон у двух исходных фотографий; сохранить лица, выражения, волосы, одежду, фигуры и позы; расположить портреты рядом на прозрачном холсте с промежутком и одинаковым масштабом, выровнять нижние края. Не добавлять фон, тени, надписи и новые части тела.

Портреты отображаются из одного прозрачного атласа с помощью CSS-кадрирования. Исходные фотографии сохранены.
