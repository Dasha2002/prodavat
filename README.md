# proДАВАТЬ — вёрстка сайта

Статический HTML/CSS/JS под последующую интеграцию с CMS. Организация повторяет проект «ДомКлимата»: каркасы страниц, HTML/CSS каждой секции рядом, общие стили, сборка секций через fetch и {{root}}.

## Запуск

`npm run dev` → http://127.0.0.1:5506

Также подходит VS Code Live Server. Не открывать через file://: браузер блокирует загрузку HTML-секций. Внешние зависимости и установка пакетов не нужны.

## Дизайн

- Главная, светлая концепция: `/`
- Главная, контрастная концепция: `/?design=contrast`
- Контакты: `/kontakty/`
- Контакты с сохранением второй концепции: `/kontakty/?design=contrast`
- Переключатель концепций находится в верхней полосе превью. Это инструмент согласования, удалить перед запуском.

## Структура

```text
index.html                 Главная: каркас и порядок секций
kontakty/index.html        Контакты
politika/index.html        Описание обработки данных демоформы
404.html                   Страница ошибки
css/styles.css             Точка входа, импорты секций
css/reset.css              Сброс
css/fonts.css              Локальный Montserrat
css/base.css               Палитра, типографика, общие элементы
css/pages.css              Внутренние страницы
js/include-sections.js     Загрузка секций, подстановка {{root}}
js/design.js               Концепция из URL, до первого рендера
js/app.js                  Меню, ссылки, демонстрационная форма
sections/<имя>/<имя>.html   Разметка секции
sections/<имя>/<имя>.css    Стили секции
img/brand/                 Логотип и favicon
img/team/                  Фото с прежнего сайта
fonts/                     Шрифты без внешних запросов
docs/sitemap.md            Маршруты следующего этапа и наполнение
scripts/serve.mjs          Локальный сервер без зависимостей
scripts/check.mjs          Проверка ресурсов и порядка секций
```

На главной `data-root=""`, во внутренних страницах `data-root="../"`. В общих секциях пути начинаются с `{{root}}`. JS инициализируется на событии `sections:loaded`. Имена классов следуют БЭМ. При переносе в CMS секции заменяются серверными шаблонами, CSS сохраняется.

## Исходные материалы и решения

Карта сайта определяет порядок секций главной. Брендбук: #1B1717, #F5F5F7, #8D1223, #3D4045; Montserrat для текста; SF Pro Text для заголовков на Apple-устройствах, системные Segoe UI/Arial на остальных. Файлы SF Pro не предоставлены и не включены. Логотип и фото взяты с прежнего сайта. Фотографии не привязаны к именам: соответствие требуется подтвердить.

Указанный `.agents/skills/taste-skill/SKILL.md` отсутствует. Проверены доступные локальные skills и Downloads; использованы рекомендации существующего `.agents/skills/redesign-skill/SKILL.md`. Файлы skill не изменялись.

## Демо и подготовка к запуску

Контакты и реквизиты демонстрационные по согласованию: телефон с кодом 000, зарезервированный домен .example, нулевые регистрационные номера. Они не являются данными реального лица. Мессенджеры не подключены. Форма валидирует поля, готовит текст и копирует его; не отправляет и не хранит данные. Успешная отправка не имитируется.

До запуска заменить реквизиты, включить отправку формы через сервер, опубликовать утверждённую политику и согласие, согласовать стоимость встречи, дополнить биографии и соответствие фото, добавить реальные кейсы и отзывы. Цены, результаты, опыт и отзывы не выдумывались. Разделы под кейсы и отзывы включены в нужных местах, с честным статусом наполнения.

`npm run check` проверяет локальные ссылки, ресурсы и структуру. Проверка синтаксиса JavaScript выполнена через `node --check`. После перезапуска сервера проверены в браузере оба варианта главной, контакты, переходы, загрузка фото, мобильное меню и демонстрационная форма. На ширине 390 px главная и контакты не имеют горизонтального переполнения. Репозиторий не публиковался, коммиты и push не выполнялись.
